## Behavior And Acceptance

This ports the previously demonstrated controls onto the shipped standalone app,
not over it. Capture, library management, import/export, standalone Stop/reuse,
and per-Play fresh-profile behavior remain. Explicit UI switching alone reuses
its dedicated profile and restores completed history without new requests.

Changes:

- Native VS Code/experimental Agents selector, safe only at response boundaries.
- One draggable rounded overlay, default amber frame and native color picker.
- Independent prompt and timer selection; `HH:MM:SS` accumulated response work,
  interpolated over accelerated output, excluding inter-turn user idle time.
- Prompt excerpts separate from source data; optional curated playlist summaries.
- Read-only JSON displays for saved rich parts in Editor; no saved edit execution.
- A bounded startup retry for an observed control-file sharing violation.

New runtime file: `ReplayPresentation.ps1`, explicitly included in
`packaging/Build-Windows.ps1`. Existing production `playwright`/`ws` dependencies
are reused; no dependencies or package format version changed.

Source checks (run from this worktree; do not use original workspace evidence):

```powershell
Set-Location native
npm run test:unit
npm run lint
Set-Location ..
powershell.exe -NoProfile -ExecutionPolicy Bypass -File test/packaging.ps1 -NodePath <node.exe>
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test/controller-ui.ps1 -NodePath <node.exe> -EvidenceRoot <isolated-evidence>
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test/presentation-ui.ps1 -EvidenceRoot <isolated-evidence>
```

The existing default unit command selects the replay and library regressions.
The standalone UI harness covers capture/save, rename/select, pause/resume,
review/completion, scoped Stop, controller reuse, closing paused replay, and
library persistence after restart. The presentation harness uses only generated
synthetic recordings and checks the combined/timer-only/summary-only layouts,
native RGB selection and actual frame pixels, moving seconds, pause holds,
idle-gap exclusion, disabled in-response mode selection, and scoped cleanup.

Native Editor content/timing/history verification uses `npm test` with
`HISTORY_REPLAY_TEST_SOURCE` pointing at the synthetic source generated by the
presentation harness and `HISTORY_REPLAY_TEST_REQUEST=0`.
